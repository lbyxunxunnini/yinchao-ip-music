# 阶段 2：歌词与曲风创作

目标：写一首有目标指纹、具体画面和可唱性的歌。方法统一单轨——不分角色/话题两套规则，只让「核心命题从哪来」随目标类型自适应。

本阶段由当前主上下文直接创作，不创建子代理，不做独立评审。用户是唯一语义验收者。

## 创作流程

### 1. 读取素材，建立核心命题

先读取阶段 1 产物（素材卡 + 创作简报），明确 `subject_mode`：

- 角色 / IP 目标：从角色证据（具体行动、可感知的物件/场景/身体状态、关系转折或内在矛盾）提炼命题。
- 话题 / 热点 / 曲风 / 受众目标：从目标冲突、受众处境或时代语境提炼命题，不得把非角色目标虚构成角色模式。

核心命题必须同时满足：

- **换成其他目标仍成立则不合格**——必须是当前目标的指纹；
- 能容纳至少三个不同素材，而不是只能解释一个场景；
- 有动词、有对象、有取舍——不是静态描述或抽象论证；
- 能通过具体画面表达，不能只靠「我不认命」「我只爱你」一类口号。

### 2. 核心命题 5 项自检（写任何歌词之前）

任一不通过就回候选重选；2–3 个候选全部失败时回到素材重新寻找矛盾点，不降低标准：

1. **替换目标**：换成一个不同作品/世界观/话题。仍然成立 → 不合格，这是通用口号。
2. **证据承载**：至少三个不同素材能证明命题；只能反复解释一个称呼或身份 → 不合格。
3. **裸念三遍**：不靠旋律念 Hook 三遍，第三遍记不住节奏和重音 → 不合格。
4. **重量差**：命题开头和结尾的含义必须不同；无论主歌怎么写都不变重 → 不合格。
5. **看见什么**：命题和 Hook 里有听众能看见、听见或身体感受到的东西 → 没有则不合格。

自检无顺序要求，五条全过才能写歌词。

同时内部明确：谁在唱、唱给谁、命题在歌曲开始与结束时的重量。

### 3. 提炼 Hook

从核心命题提炼 Hook——短、可唱、有重音，只承担点题作用。提出 2–3 个真正不同的候选，朗读比较语言质感、画面、情绪张力与复唱欲望，选最自然的一版。不要把同一个 Hook 拆散到每个主歌、桥段和尾奏。

### 4. 副歌先行，反推全歌

先写副歌（核心命题的集中展开形态），再写主歌。每个主歌回答一个问题：**为什么当前目标必须在这一处说出这句 Hook？**

- 每个主歌从不同素材和情绪功能逼近同一命题，每段有独立情绪中心；
- 素材可以证明选择、代价、克制、失控或关系变化，但不能按事件/时间线排成履历目录；
- 副歌重复时，每次回归至少改变其余句子的画面、代价或后果；
- 三次落点可参考：第一次唱出立场，第二次唱出代价，第三次唱出不可逆后果。

完成后大声朗读：删掉解释性重复，修正难断句、只有书面逻辑没有口语呼吸的句子。

### 5. 履历化与反口水检查（写完自查）

- 主歌按时间/地点顺序复述履历 → 必须重写；
- 多个段落只是「名字、身份、面纱、深情」等同一语义换词 → 必须重写；
- 每个主歌至少有一个具体动词和一个可感知细节；
- 连续两句抽象宣言必须改写为场面、动作、物件或身体感受；
- 删除 Hook 后，歌词仍应保留目标的行动、矛盾或关系指纹。

允许直白、专名、事件、时间线、抽象落点和传统意象，只要它们服务核心命题且没有让素材清单或通用口号成为歌曲骨架。

### 6. 曲风跟随核心命题

比较 2–3 个听感明显不同的曲风方向，选择最能托住核心命题、语言质感和情绪推进的一种。题材标签不得自动决定曲风（古风不等于必然用某种编曲）。

曲风描述为中文自然语言，可直接供生歌使用，必须包含：曲风、速度与节奏、配器、情绪基调、人声取向。不写英文声音导演稿。

## 长度约束（生歌 API 硬限制）

- 歌词 ≤ 3000 字符；
- 曲风描述 ≤ 1000 字符。

超限必须删改后提交，不得带着超长输入进入生歌。

## 产物

```text
{位置}/{目标名}/songs/
├── {目标名}-{歌名}-歌词.md
└── {目标名}-{歌名}-曲风.md
```

格式见 [references/output-templates.md](../references/output-templates.md)。歌词曲风完成后必须展示完整歌词与曲风给用户验收。

## 用户验收

- **接受**：阶段 2 完成，允许进入生歌。
- **修改**：保留用户原话，修改歌词或曲风后重新展示。修改必须产生**实质变化**：歌词或曲风的源内容被改写（新增/重写段落、更换意象、调整结构、重立 Hook 等）。仅调整段落标签、重排版、同义换词或改动无关字段不算实质变化，不得重新提交验收。
- **取消**：停止并保留当前文件。

机器检查（长度、格式）通过不代表用户接受。**用户预览确认（接受）前，阶段 2 未完成，不得进入阶段 3、不得提交生歌。** 用户明确只要歌词曲风（启动路径 1）时，此处即完成交付；全链路模式（路径 2）在用户接受后才进入阶段 3。
