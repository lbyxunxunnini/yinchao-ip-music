# 阶段 1：联网搜索分析

目标：把用户给出的任意目标（角色、IP、人物、热点话题、曲风、受众等）变成两份可直接用于写歌的产物——**素材卡**与**创作简报**。

本阶段由当前主上下文直接搜索与创作，不创建子代理，不做独立评审。

## 输入

用户说出任何创作目标即可启动，不要求用户选择任务类型。目标示例：

- 角色 / IP：某小说角色、某游戏 IP、某历史人物、某品牌 IP
- 热点：某事件、某流行趋势、某社会话题
- 曲风 / 风格：古风、蒸汽波、国潮
- 受众：给 Z 世代、给某圈层

最小输入是「目标是什么」。目标模糊时先简短提问（问一次），不反复猜测。

## 工作流

```text
解析输入
→ 自动判断分析侧重（角色资料 / 热点时效 / 曲风参考 / 受众共鸣）
→ 制定查询计划（多组关键词）
→ 联网搜索，逐条记录 raw_findings（URL、来源类型、搜索日期、摘要）
→ 清洗分层：事实 / 观点 / 创作假设
→ 产出素材卡 + 创作简报
→ 运行自检清单（11 条）
→ 展示给用户 → 接受 / 修改 / 补搜
```

搜索时直接使用当前环境提供的普通网页搜索能力；搜索必须保留实际 URL、来源类型和搜索日期，不得伪造搜索结果。

搜索失败或素材不足时的降级：

- **首轮补搜**：有效来源不足时，先自动换一组关键词二搜（目标名变体、相关主题、社区平台），二次搜索后才进入降级判定，不因一次搜索就降级。
- **来源簇**：多个平台报道同一内容计为同一来源簇；素材充足度以「3 个不同 URL 或 2 个以上来源簇」为正常线。

降级路径（按素材充足度分层，产物必须如实标注）：

- **L1 正常**：≥3 个不同 URL 或 ≥2 个来源簇 → 正常流程。
- **L2 轻度不足**：仅 2 个 URL → 可继续，素材卡「来源充足度」标记为轻度不足，「缺口提示」必须显式说明「素材仅 2 来源，创作假设占比升高」。
- **L3 严重不足**：≤1 个 URL 或搜索工具不可用 → 不硬产出素材卡，告知用户三选一：重试搜索 / 更换或收窄目标 / 基于创作假设交付（创作假设必须全部显式标记，不伪装成事实）。

搜索必须保留实际 URL、来源类型和搜索日期，不得伪造搜索结果；降级时不得硬凑来源。

## 产物

1. `{位置}/{目标名}/{目标名}-素材卡.md`——素材卡（模板见 [references/material-card-template.md](../references/material-card-template.md)）
2. `{位置}/{目标名}/{目标名}-创作简报.md`——创作简报（模板见 [references/creative-brief-template.md](../references/creative-brief-template.md)）

两份产物都写入后，按「位置与产物目录」规则确认目录已创建。

## 自检清单（11 条）

展示给用户前逐条检查，任一条不满足先补齐再展示：

1. 素材卡基本信息完整：目标名称、目标类型、来源数量、来源充足度。
2. 至少 3 个不同 URL 来源，或 2 个以上来源簇（多个平台报道同一内容计为同一来源簇）。
3. 每条事实必须有 URL。
4. 观点必须显式标记为观点，不得混入事实。
5. 不允许整段复制网页文本，全部转为提炼。
6. 没有 URL 的内容只能进入「创作假设」，不能写成事实。
7. 热点/趋势类目标必须记录搜索日期与时间窗口，注明时效。
8. 创作简报的「歌核」非空（一句话概括这首歌要表达什么）。
9. 「歌词方向」非空（明确素材如何进入歌词）。
10. 「曲风方向」非空（明确的曲风与情绪基调）。
11. 「缺口提示」明确（素材不足处列出缺口，供用户决定是否补搜）。

脚本不评价素材是否真实、是否有创作价值——这些判断属于用户验收范围。自检只做确定性工程检查（字段存在、URL 数量、分类标记）。

## 用户验收

向用户展示素材卡与创作简报（两份完整内容，不展示内部过程）：

- **接受**：素材充分，进入阶段 2。
- **修改**：保留用户原话，修改后重新自检并展示。
- **补搜**：素材不足，根据缺口重新搜索，产出新的素材卡与简报。

用户要求重做已交付素材时，创建新的搜索轮次；旧产物在新产物验收通过前保持不变。

## 常见错误（禁止）

- 只有网页摘要，没有创作转化
- 把评论当事实
- 无 URL 结论
- 直接复制网页文案
- 素材用途不明（素材不说明服务歌词还是曲风）
- 热点没有时间窗口
- 素材不足时硬凑，不列缺口
