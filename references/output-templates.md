# 阶段 2 输出模板

## 歌词文件：`{目标名}-{歌名}-歌词.md`

```markdown
# {歌名}

> 目标：{目标名} · 由 yinchao-ip-music 阶段 2 创作

## 核心命题

{一句话：这首歌唯一成立的立场/矛盾}

## 歌词

[INTRO]

...

[VERSE 1]

...

[CHORUS]

...

[VERSE 2]

...

[CHORUS]

...

[BRIDGE]

...

[OUTRO]

（结构标签按歌曲需要增减；歌词字符数 ≤ 3000）
```

## 曲风文件：`{目标名}-{歌名}-曲风.md`

```markdown
# {歌名} 曲风

> 目标：{目标名} · 由 yinchao-ip-music 阶段 2 创作

## 曲风描述（中文，供生歌直接使用，≤ 1000 字符）

{一段中文自然语言：曲风、速度与节奏、配器、情绪基调、人声取向，
能托住核心命题与歌词语言质感}
```

## 生歌输入约定

生歌时取两份文件的核心内容组装：

- 曲风（`--prompt`）：曲风文件中的「曲风描述」段落
- 歌词（`--lyric`）：歌词文件中的「歌词」部分（含结构标签）

组装后再次确认：歌词 ≤ 3000 字符、曲风 ≤ 1000 字符。

传参方式（与 stage3 规则一致）：

- 内容简单（无特殊字符）时可直接内联传参（`--prompt`/`--lyric`）。
- 内容含引号、`$`、反引号或为多行文本时，先把纯文本内容写入临时文件，用 `--prompt-file`/`--lyric-file` 传文件路径，避免 shell 解析问题。
